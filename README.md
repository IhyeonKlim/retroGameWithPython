프로젝트 소개
이 프로젝트는 프로그래밍 입문자와 게임 개발에 관심 있는 모든 이를 위한 실용적인 가이드입니다. 가장 쉽고 강력한 언어인 Python과 2D 게임 개발에 최적화된 라이브러리 Pygame을 사용하여 추억 속의 레트로 게임들을 직접 만들어보는 과정을 담고 있습니다.
단순히 코드를 따라 치는 것을 넘어, 게임의 **핵심 원리(충돌, 움직임, 렌더링)**를 이해하고 **객체 지향 프로그래밍(OOP)**을 자연스럽게 습득할 수 있도록 단계별로 구성되어 있습니다.

🛠️ 기술 스택
주요 언어 : Python 3.x
간결하고 읽기 쉬운 문법을 가진 범용 프로그래밍 언어입니다.

게임 라이브러리 : Pygame
2D 그래픽, 사운드, 입력 처리를 쉽게 할 수 있는 파이썬 게임 개발 도구입니다.

개발 환경 : PyCharm (권장)
파이썬 개발에 최적화된 통합 개발 환경(IDE)입니다.

알카노이드 기반 벽돌 깨기 게임 (복잡한 충돌, 아이템 시스템)

버추어 캅 기반 경찰 FPS 게임 (마우스 컨트롤, 동심원 판정, 적/인질 객체 관리)

스페이스 인베이더 기반 우주 침략자 게임 (적 무리 관리, 탄막, 벽 시스템)

드래곤 플라이트 기반 용 비행 슈팅 게임 (스크롤링 배경, 모듈화, 보스전)

스트라이커즈 1945 기반 스페이스 탄막 슈팅 게임 (복합 탄막 패턴, 시나리오 파일)

설치 및 실행 방법

이 프로젝트의 코드를 실행하기 위해서는 Python과 Pygame 라이브러리가 필요합니다.

1. 파이썬 개발 환경 구축

Stage 01, Level 1의 자세한 설치 가이드를 따르세요.

Python 설치: Python 공식 웹사이트에서 최신 버전을 다운로드 및 설치합니다.

PyCharm 설치: JetBrains PyCharm 웹사이트에서 Community 버전을 다운로드 및 설치합니다.

프로젝트 생성: PyCharm을 실행하고 새 프로젝트를 생성합니다.

2. Pygame 설치

프로젝트 터미널에서 다음 명령어를 실행하여 Pygame 라이브러리를 설치합니다.

pip install pygame


3. 코드 다운로드 및 실행

이 저장소를 git clone 하거나 코드를 다운로드합니다.

PyCharm에서 원하는 게임 파일(예: Level06_Pong.py)을 열고 실행합니다.

Stage 02: Pygame이라는 전설의 아이템을 얻자!

Level

내용

핵심 목표

Level 3

첫 번째 퀘스트, Pygame 장착하기

Pygame의 기본적인 구조(초기화, 종료, 프레임, 좌표, 색상)를 이해하고 "Hello World"를 화면에 그립니다.

Level 4

두 번째 퀘스트, Pygame 수련하기

Pygame을 활용하여 반응 속도 테스트, 초간단 탁구 게임 등 실제 작동하는 미니 게임을 만들어봅니다.

Level 5

세 번째 퀘스트, 화면 보호기

클래스를 활용한 객체 지향 프로그래밍(OOP) 개념을 적용하고, 시각적 몰입감을 주는 '운동 시차' 원리를 구현합니다.

Stage 03: 레트로 게임 던전 탐구하기

Level 6

레트로 게임 마스터 1, 탁구 게임 (Pong)

함수화 및 클래스를 활용하여 복잡한 게임 로직(충돌, 가속, 멈춤 없는 키 입력)을 체계적으로 구현하고 PEP 8 코드를 정리합니다.

Level 7

레트로 게임 마스터 2, 벽돌 깨기 게임 (Breakout)

복합 충돌 판정의 원리를 이해하고 아이템 시스템을 추가하여 게임에 깊이를 더합니다.

Level 8

레트로 게임 마스터 3, 총알 피하기 게임 (Dodge)

게임 상태 관리의 중요성을 이해하고, 최고 점수 기록 시스템과 BGM/이미지 추가 기능을 구현합니다.

Stage 04: 레트로 게임 던전 중간 보스전

Level 9

레트로 슈팅 게임 마스터 1, 경찰 FPS 게임

총기/플레이어/적/인질 객체를 구현하여 OOP 심화를 다루고, 마우스 기반의 정밀한 충돌 판정을 구현합니다.

Level 10

레트로 슈팅 게임 마스터 2, 우주 침략자 게임 (Space Invader)

적 무리(Group) 관리, 탄막 구현, 벽 시스템을 통해 게임의 난이도와 전략성을 높이는 방법을 배웁니다.

Stage 05: 레트로 게임 던전 최종 보스전

Level 11

비상하는 용의 전설, 용 비행 슈팅 게임 (Vertical Shooter)

대규모 게임 프로젝트를 위한 모듈화 및 파일 분리 기법을 적용하여 완성도 높은 스크롤 슈팅 게임을 만듭니다.

Level 12

스페이스 탄막 슈팅 게임 (Bullet Hell)

시나리오 파일을 활용하여 적의 등장 패턴을 외부에서 관리하고, 특수 스킬 및 복합적인 탄막을 구현합니다.
